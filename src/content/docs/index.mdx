## Why Lumina

<CardGrid>
  <Card title="Vulkan renderer" icon="rocket">
    A bindless, GPU-driven renderer with clustered lighting, cascaded shadows,
    image-based lighting, volumetric fog, and a Slang shader pipeline.
  </Card>
  <Card title="Data-driven world" icon="puzzle">
    A sparse-set entity-component world with a reflection system that powers the
    editor, serialization, and networking.
  </Card>
  <Card title="C# scripting" icon="open-book">
    Gameplay in C#, with in-editor hot reload, a typed component API, a message
    bus, and editor tooling built around it.
  </Card>
  <Card title="Editor first" icon="laptop">
    A full editor, the scene outliner, inspector, asset browser, and live tools,
    on the same runtime as the game.
  </Card>
</CardGrid>
